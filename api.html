API del curso

JSON de solo lectura, sin claves ni backend: cada archivo del repositorio es un endpoint. Mismo patrón que la API del Tanaj.

Endpoints

RutaContenido
v1/index.jsonPortada: conteos, cobertura del vocabulario, fuentes y licencias.
v1/alefbet.json27 formas (22 letras + 5 finales): nombre, sonido, transliteración, gematria, código Unicode, ejemplo real del Tanaj y audio.
v1/niqqud.json55 signos: vocales, jatuf, sheva, dagesh, te'amim y puntuación del códice.
v1/vocab/top100.json · top300 · top1000Vocabulario por frecuencia con glosa en español, ocurrencias, cobertura acumulada y referencia.
v1/lexicon/<H####>.jsonLéxico Strong: lema hebreo, transliteración, pronunciación, definición, etimología, formas del Tanaj. Índice en v1/lexicon/index.json.
v1/lessons/index.json · v1/lessons/NN.jsonLas 12 lecciones: objetivos, ítems, ejercicios y la explicación en HTML.
v1/reading/index.json · v1/reading/<slug>/<cap>.jsonPasajes interlineales: por versículo, hebreo, español y análisis palabra por palabra (forma, Strong, transliteración, glosa).
v1/audio/index.json253 clips MP3 (letras, niqqud, 100 palabras, versículos de los pasajes) con su texto.
v1/manifest.jsonRuta → bytes y sha256 de todo lo publicado.

Ejemplos

# la letra alef, con su ejemplo real y su audio
curl -s https://aprendehebreo.github.io/v1/alefbet.json | jq '.items[0]'

# la palabra más frecuente del Tanaj (H853, את)
curl -s https://aprendehebreo.github.io/v1/vocab/top100.json | jq '.items[0]'

# etimología de רֵאשִׁית (H7225)
curl -s https://aprendehebreo.github.io/v1/lexicon/H7225.json | jq '{he, xlit, def_en, raices}'

# Bereshit 1 palabra por palabra
curl -s https://aprendehebreo.github.io/v1/reading/bereshit/1.json | jq '.versiculos[0].palabras[0]'

# audio de la letra alef
curl -sO https://aprendehebreo.github.io/v1/audio/letra-01.mp3

Forma de un clip de audio

"v1/audio/letra-01.mp3": {
  "texto": "אָלֶף",              // lo que dice el audio
  "grupo": "letra",              // letra | niqqud | palabra | verso
  "ref_id": "alef",              // id del ítem, o "bereshit/1/1" en los versículos
  "bytes": 12528
}

Cómo se generó

  • Hebreo y morfología: Westminster Leningrad Codex (morphhb), CC BY 4.0.
  • Léxico: Strong's Hebrew Dictionary, dominio público.
  • Español: Reina-Valera 1909, dominio público (getbible v2).
  • Letras y signos: Unicode Character Database (Unicode License): los nombres oficiales no se escriben a mano.
  • Audio: edge-tts con la voz he-IL-HilaNeural (voces he-IL de Microsoft Edge), ritmo −10 %. Se puede sustituir por grabaciones propias: el build solo necesita MP3 con el mismo nombre.

Los conteos y la cobertura del vocabulario se comprueban en cada build: python3 build/verify.py. Si algo no cuadra, el build falla.

CORS y uso desde otra web

GitHub Pages responde con access-control-allow-origin: *, así que puedes consumir la API desde cualquier sitio. Para caché inmutable por versión usa jsDelivr: https://cdn.jsdelivr.net/gh/aprendehebreo/aprendehebreo.github.io@v1.0.0/v1/alefbet.json.
